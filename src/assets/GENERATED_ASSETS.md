# Generated artwork

Both assets were generated with the built-in image-generation tool. The reference PNGs in the project root provided visual guidance; their UI is implemented in Vue.

## twilight-lakeside.png

Reference: `Twilight Lakeside Reading Timer.png`

Final prompt:

> Use case: stylized-concept. Asset type: full-screen background artwork for a reading timer app. The attached image is a reference for scenery, composition, and palette ONLY. Generate a clean portrait illustration of the same quiet twilight lakeside view from a library window: distant mountains, violet dusk sky and calm lake, dark shelves and trailing leaves at the edges, open book on a foreground desk and a small softly glowing amethyst lantern. Dark indigo, muted purple, restrained warm lamp light, painterly detailed atmospheric style. Keep broad dark negative space in the middle for live timer text that will be rendered separately by code. Remove ALL UI, text, numbers, clocks, cards, buttons, icons, borders, and watermarks. Only environmental artwork. Portrait 2:3 composition, polished high quality.

Final prompt:

> Use case: stylized-concept. Asset type: wide atmospheric header illustration for a dark library administration app. Images 1 and 2 are references for the scenery and palette only. Create a panoramic, painterly library interior at night, softly glowing violet window and bookshelves on the right, a desk with neatly stacked clothbound books, small warm reading lamp and plant in the lower right. The left half should be quiet near-black negative space that naturally fades into the scene; there will be live HTML headings over it. Deep ink navy and amethyst, restrained warm highlights, premium detailed illustration consistent with the supplied reference images. Wide 3:1 composition. Absolutely NO user interface, text, typography, numbers, icons, panels, borders, graphs, robots, or watermark. Only the library environment.
